# 一年级换课小助手

锦田小学一年级换课查询工具（交接自陈妍捷老师，2026年9月）。

**在线使用**：<https://jtprimary-school.github.io/Jtprimary-school-huanke/>

手机浏览器打开，选好 **日期 + 班级 + 星期 + 节次**，即可查询：

- 本班该节次的课程与任课老师
- 该节次没课、可以换课的老师名单
- 老师该时段可能有科组会时会标注提醒（不剔除，建议先沟通确认）

纯静态单文件工具，无需服务器、无需登录。

## 换学期如何更新数据

所有数据内嵌在 `index.html` 的 `<script>` 中，共 3 处：

1. **老师课表**（变量 `T`）：`{"老师姓名": [[星期, 节次, "科目", "班级", 周型], ...]}`
   - 星期 1=周一…5=周五；节次 1~6；班级写法如 `一(8)`；周型 `0`=每周 / `1`=仅单周 / `2`=仅双周
   - 换学期整块替换 `T` 即可
2. **单双周起始日**（`weekInfoOfDate` 内的 `new Date(2026,8,1)`）：即第一周（单周）开始日期，注意月份从 0 数起（8 = 9月）
3. **科组会时间**（变量 `MEETINGS`）：`{day:4, periods:[3,4], subj:"语文"}` 表示周四上午 3、4 节语文科组会

改完 push 到 main 分支，GitHub Pages 一分钟内自动更新。

## 数据核对依据

原始课表转录自全校 27 位老师的课表截图（2026-2026 学年第一学期），截图备份于资料库，未纳入本仓库（避免公开传播教师课表照片）。
